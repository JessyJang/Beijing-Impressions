# 参考粒子运动复查（2026-09-13）

用户反馈：只认可当前四面钟聚拢，其他五种效果不满意。四面钟应保留；本轮仅分析，没有修改表现代码。

重新从用户提供的 a02f336376f36c1971f682343d34c855.mp4 提取 64 张连续采样画面：开头每 0.5 秒、穿门每 0.5 秒、白塔每 0.8 秒、离场每 0.65 秒。接触表在 references/video-02/review-v39。此采样能看空间与形态演变，不能确定逐粒轨迹或原片底层技术，也不是帧率/连续播放性能测量。

- 0–7.5 秒：可辨局部、稀疏碎屑、大颗粒近景交替出现；建筑逐渐可读，镜头尺度也变化。并非全体粒子同时完成同一种几何动作。
- 25–37 秒：塔的部分轮廓与不规则丝状/薄片状结构并存；形态存在连续牵拉和局部卷曲，清晰局部与松散局部形成对比。
- 58–67.75 秒：檐口逐渐放大、越过镜头，近处颗粒变大，周围结构部分松散。离场的运动由建筑局部、粒子与相机共同承担。

当前 v38 问题：
1. 祈年殿统一极坐标环绕容易像圆筒收缩，规律太明显。
2. 四合院 offset 随 horizontal/vertical 阶段衰减，像整块组件平移；CCTV 按楼层左右交替同样容易像拼装。
3. 中国尊竖直缩放和角楼整体斜移保留过多整块结构关系，只有移动方向不同，缺少局部松散牵引。
4. 大部分表面点同等承担流动；大量细点铺满画面容易形成噪点雾，缺少少量清楚的近景粒子、连贯中景流束和稳定的建筑识别部分。

下一步设计原则：保留四面钟现有效果；其他建筑共享自然的曲线流动语言，通过空间分组、局部进度、主流与支流、大小虚实差异形成变化；去掉可辨的整圈、整层、整块搬运动作。不以随机扰动替代有方向的流动，也不把原片解释为所有建筑统一从无到有。
