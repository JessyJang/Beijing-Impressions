# 第 1 课：一个 3D 画面如何出现

目标：能用自己的话解释场景、摄像机、物体、灯光和渲染器。今天先体验，不用记住代码。

## 1. 转动视角

打开首页，用鼠标拖动展台，用滚轮缩放；手机上单指拖动、双指缩放。

观察：物体仍在展台上，你是换了观察它的位置。`OrbitControls` 控制摄像机绕目标移动。

## 2. 换形状

把「扭结」改为「方块」，再改为「球体」。

观察：平面之间的明暗跳变明显，球体的高光较连续。同一套灯光照在不同形状上，会产生不同的视觉效果。

代码位置：`src/main.js` 中的 `geometries`。几何体描述形状，`material` 描述表面；两者组成 `Mesh`（网格物体）。

## 3. 调灯光

把主光从 3 调到 0，再调到 6。

观察：主光亮度、高光和阴影对比改变。0 也不全黑，是因为还有 `HemisphereLight` 环境补光。

## 4. 打开线框

选球体，勾选「显示三角形线框」。

观察：光滑外观下面是一个由小三角形组成的网格。高斯泼溅在之后的课中会用另一种表示方式呈现场景；本课没有高斯泼溅。

## 5. 第一次改代码（可选）

在 `src/main.js` 找到 `color: '#69834b'`，改为 `color: '#c9784c'`，保存后刷新浏览器。

预期：物体从绿色变成陶土色。改错了可恢复原值。这个小服务器不会自动刷新，需要手动刷新页面。

## 今天的理解

场景像摄影棚，物体像展品，材质像展品表面，灯光负责照明，摄像机决定取景，渲染器把结果画成屏幕上的像素。

完成后告诉我：**打开线框之后你看到了什么？主光调到 0 为什么仍能看见物体？** 不需要专业术语，按自己的理解描述即可。

如果无法显示：先确认终端运行着 npm run dev；若缺少依赖，执行 npm install；若提示 WebGL 2 不可用，尝试支持 WebGL 2 的浏览器并检查图形加速。
