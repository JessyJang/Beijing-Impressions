# 学习路线

长期作品方向：一个可自由观察的实景空间，叠加可控 3D 展品和三个导览热点。可以选网球场、工作室或小展厅，具体题材等待用户选择。

| 阶段 | 做出什么 | 只学哪些关键概念 | 状态 |
| --- | --- | --- | --- |
| 01 基础场景 | 可旋转观察的 3D 展台 | 场景、摄像机、网格、材质、灯光 | 已实现，等待学习反馈 |
| 02 高斯泼溅 | 加载一个许可清楚的小型 splat 样例 | 网格与高斯的区别、加载、坐标和尺度 | 待开始 |
| 03 混合场景 | 同屏展示 splat 和传统模型 | 位置对齐、深度遮挡、渲染差异 | 待开始 |
| 04 热点导览 | 三个可点击热点与说明卡 | 点击检测、镜头移动、页面信息 | 待开始 |
| 05 自己的空间 | 引入自己或获得授权的扫描 | 采集与渲染的区别、文件大小、画质取舍 | 待开始 |
| 06 作品整理 | 手机适配和可复用场景 | 性能预算、降级、资源登记 | 待开始 |

每课流程：先看效果 → 做一个小操作 → 解释发生了什么 → 改一处代码 → 记下发现。根据反馈调整节奏。

高斯泼溅的网页渲染器不等于重建工具。照片/视频转为高斯场景需要另一个采集和训练流程，等第 5 阶段再按设备与预算选择。
