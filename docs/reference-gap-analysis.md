# 北京印象：参考视频与当前版本的差距

## 分析范围与结论

按用户最新反馈重新分析 fe5a53ae270832b79522b105ee65882b.mp4（约 82.83 秒）。本次在本机每秒采样，共查看 83 个时间点，并对照当前网页 1 秒、4.5 秒画面及源码。未分析音轨；单秒采样不用于断言亚秒级剪切方式。仅凭成片不能确认原作者采用点云、高斯泼溅、网格采样或后期技术，也不能确认前后场景的粒子有逐一对应。

结论：当前实现改善了静帧材质，但没有实现参考作品的空间组织和形变。点数不是关键瓶颈，单视图浅表面结构、缺乏主体聚散、独立动态素材不足、镜头范围过小才是根因。

## 当前实现为什么像照片

### 点是绘制单位，但布局还是单张图片

src/memory-scenes.js 按每个像素生成一个彩色点，深度只由 depthAt(u,v,shot) 的几个手工函数赋值；每个像素方向只有一个表面样本。人物、蒸笼、墙体、门后空间没有独立完整体积，也没有遮挡后面的素材。它像浅浮雕的画面，不能靠增加采样点得到更多侧面。

点的颜色和位置基本保持原图关系；密集重叠后自然重新拼出原图。目前无全体粒子的散布初态、汇聚轨迹与对象级目的位置。因此用户觉得「不是粒子慢慢组成」是准确的感受，不能用“有 40 万点”来证明这个体验已实现。

### 镜头与转场的幅度和结构不足

src/main.js 的每段长度固定为 5 秒；缩放范围约 2.5%–6.5%，横向位移为整个 20 单位画面宽度中的 0.13–0.20 单位，主要看向固定中心。转场只是末 0.25 秒和下段初约 0.225 秒的边缘散开与轻微降透明度；在 5 秒、10 秒处隐藏上一组、显示下一组。

只有微弱晃动、整体推近和边缘抖动，没有空间中的进入、掠过、环绕、穿越，也没有粒子轨迹把观众带入下一段。

### 热气、树叶和雪仍大量固定在图里

确认稿原图已经画入白色蒸汽、悬空树叶和雪花。这些像素采样后仍留在原地。额外叠加的动态层不会移除固定的蒸汽或雪，因此主体看上去仍静止。

当前确实另有 180 个蒸汽点、160 个暖色飘落点、1600 个雪点，但蒸汽只是软圆点叠加；暖色点没有叶片的形状、翻面和落地；雪没有与屋檐、宫墙正确配合的遮挡/接触。主场景和效果材质都不写深度，无法依靠现有深度缓冲自然完成建筑挡雪。鸟也仅是源图局部点群平移，非独立振翅对象。

## 下一版应改变的制作方式

1. 已认可图保留为构图、材质、色彩标准。先提取无蒸汽/无飞叶/无落雪的干净静态底材，动态元素单独制作；不继续把完整的有特效成图作为唯一场景数据。
2. 优先做好一个可检验的立体局部：院门/门洞与早餐摊，或真实建筑转角。建立物体之间的深度、侧面和遮挡；大角度变化需要多视图、许可明确的三维资产或依据实物参考的建模。单图加深度只能有限视差，换渲染器不能自动补出真实结构。
3. 场景粒子有散布位置、结构位置和过渡轨迹；点群按门框、砖墙、蒸笼、人物等对象分批显形，主体也参与散开。通过空间与时间组织看出“组成”，不依赖更大的白点。
4. 热气从蒸笼口持续生成，上升、卷动、膨胀、消散；叶片独立翻转、随风横移、从近处掠过；雪有近中远层次，在屋檐前后形成遮挡。动态应在相机固定时仍明显可见。
5. 转场先设计一段：胡同成形 → 斜向靠近蒸笼 → 热气与场景点群形成流动遮挡 → 冷色雪点显出宫墙转角。此为创作提案，尚未实现，也不要求冒充真实地理连续路线。

## 可直观看见的验收标准

- 开始时没有完整画面，粒子分阶段显出可辨认物体。
- 固定相机，仍能看到蒸汽变化、叶子移动、雪穿过不同深度。
- 改变观察角度，门框侧面和后方空间出现，前后遮挡变化；不只是原图倾斜或放大。
- 切镜前主体进入散开过程，粒子的运动方向引导下一镜头；不会只有突然换图。
- 保持已认可的细腻材质与建筑辨识度，不退回简单几何体。
