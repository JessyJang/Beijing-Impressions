# 当前版本已改为连续飞行

默认镜头沿负 Z 方向持续推进，五个空间沿路线排列，经过的空间移至远端循环；没有点击换景或反向退场。底部支持暂停、速度调节和重启。以下为第一版历史说明。

# 好天气回收站 · 原型 01

以用户的四张照片为视觉参考：蓝灰海岸、冷白雪山、水面碎光、水下失重。当前没有复制或上传照片，也没有从照片重建场景。全部空间为程序生成的网格表面采样点云；非高斯泼溅。

五幕：海岸门 → 云房间 → 室内草原与悬浮独角兽 → 漂浮建筑与门 → 日落收藏室。

操作：鼠标轻微环顾；滚轮、方向键、空格、右侧按钮推进；底部五段导航直达；手机向上滑动推进；可选自动漫游每幕停留约十秒。最后打开日落袋返回暖色海岸。

原型边界：天气袋是线框与彩点组成的抽象形状；独角兽为简化形体；不同城市的实景、袋子标签、声音尚未加入。转场使用镜头推进、点位扰动和闪光换景，尚非真实连通门户。照片的作用是配色与主题参考。
