## 下一轮制作应改变的标准

1. 素材选择以「可穿行的一段环境」为单位：门洞、墙角、台阶、树、远处地标能共同构图；孤立地标模型只承担其中一部分。
2. 先建立近景遮挡、中景路径、远景主体三个层次，再决定粒子显形。只摆远景地标无法靠撒更多粒子补成街巷。
3. 建筑主体保留可读局部，外围主动留空；点、碎屑、烟丝状形变有明确分工。
4. 特效要从具体门框、屋檐、墙面发生；过渡中保留地点轮廓的连续性，避免每幕都退化成同一种散点团。
5. 先检验一个短镜头：近处灰墙/树影遮挡 → 门洞边缘掠过镜头 → 远处地标被揭示 → 局部屋檐碎开衔接下一镜。北京的具体地理关系与门洞位置必须另核对，不能把任何门洞直接拼成鼓楼真实入口。
6. 验收问题是「能否感觉经过遮挡物、进入另一层空间，地点是否在形变中仍可辨认」，不再以点数、世界坐标距离或模型数量作为美术达标依据。
